Unité 2 : Échange d’informations via réseau local

Deuxième année du collège — Informatique

Leçon 1 : Le réseau local

Un réseau local (LAN) relie plusieurs appareils dans une zone limitée, par exemple une salle informatique.

  • Partager des fichiers.
  • Partager une imprimante.
  • Échanger des informations entre ordinateurs.

Leçon 2 : Les équipements réseau

  • Switch : relie les appareils d’un réseau local.
  • Routeur : dirige les données entre différents réseaux.
  • Point d’accès Wi-Fi : permet la connexion sans fil.
  • Câble Ethernet : assure une connexion filaire.

Leçon 3 : Le partage des données

Pour partager un fichier, les appareils doivent pouvoir communiquer et les autorisations nécessaires doivent être configurées.

Il faut respecter les règles de sécurité et protéger les données personnelles.
